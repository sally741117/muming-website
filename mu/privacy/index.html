MU 翻譯隱私與資料處理說明

適用範圍與聯絡

本頁說明 MU 網站及既有 LINE 群組翻譯的資料處理現況，並提供個人資料請求窗口。服務提供者為牧茗管理顧問有限公司，聯絡方式列於頁尾。其他官網工具與表單另依各自告知辦理。

處理資料與用途

瀏覽本次商品及說明頁不需 LINE 登入、不收集發票或付款資料。網站由 GitHub Pages 提供，連線會涉及必要的網路及瀏覽器資訊；部分既有頁面載入 Google Fonts 字型。

使用 LINE 翻譯時，服務會處理 LINE 傳送的使用者及群組／聊天室識別、訊息識別、時間、群組設定、送交翻譯的文字、圖片及必要近期上下文。使用已啟用語音功能時，亦會處理音檔、辨識文字或朗讀內容。這些資料用於依設定翻譯、回覆、維持群組設定、計算用量、防止重複處理及排查異常。

MU 加入群組後，其他成員送出的訊息及其中提到的第三人資料也可能進入翻譯處理。請在邀入 MU 前告知群組成員，避免提供不必要的敏感資料；加入者或付款者的行為不能取代其他成員依法需要的告知或同意。

服務商與資料流向

LINE 負責訊息與媒體傳送；OpenAI 處理翻譯所需文字、上下文、圖片或已啟用的語音功能；Railway 提供後端運算及持久儲存。翻譯回覆到群組後，群組成員可以看見。客服透過 LINE 或 Email 處理您主動提供的聯絡資料與問題。

相關服務可能涉及境外處理，不能保證所有資料僅留在台灣。各供應商的處理條件另依其適用文件；本公司不以此免除自身資料保護責任。

保存與刪除的界線

近期翻譯上下文的短期暫存，與群組設定、用量、防重、待處理事件及客服紀錄的持久保存不同；不代表所有資料在短時間後全部刪除。退出群組、登出或移除 Bot，也不代表歷史紀錄及備份已全部清除。

各類持久資料與備份的保存終點、清理作業及完整告知仍在確認，本頁不捏造固定天數或承諾立即刪除全部副本。依法應刪除、停止處理或留存的資料，須依必要目的、適用法令及個案核對。相關責任與流程須在正式付費開放前完成確認。

您的權利及不提供資料的影響

您可依法請求查詢、閱覽、複製、補充或更正，以及停止蒐集、處理、利用或刪除個人資料。請透過頁尾 Email、電話或客服 LINE 聯絡，說明使用情境及希望處理的事項。受理時會以必要方式確認您與資料的關係，避免揭露其他成員資料；請勿提供密碼或驗證碼。依法有留存義務或限制時，應就個案說明。本頁不限制法定權利或法定處理義務。

您可以只瀏覽網站而不加入 MU。若不提供必要 LINE 身分、群組設定或翻譯內容，可能無法提供相應翻譯或設定功能。網站瀏覽不代表同意未來新增的付費資料蒐集。
